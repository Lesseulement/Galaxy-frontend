# ЛР5. Фронтенд «Галактики» (React + TypeScript)

Определение расстояния до галактики по сверхновым типа Ia.
Базовое SPA для **гостя**: страницы **«Лента»** и **«Плитка»** на React, TypeScript, Vite и React-Bootstrap.
Данные берутся из mock-коллекции (`src/mock.ts`), база данных и S3 в этой лабораторной не нужны.

## Запуск

```bash
npm install
npm run dev
```

Приложение: http://localhost:3000

## Страницы

Внизу — навигационное меню из 4 пунктов: **Лента**, **Добавление**, **Плитка**, **Вход**.
В ЛР5 доступны только «Лента» и «Плитка»; «Добавление» и «Вход» недоступны (серые) — появятся вместе с авторизацией.

### Плитка — `/galaxies`

| Элемент | Тип | Что делает |
|---|---|---|
| Заголовок «База галактик» | текст | — |
| «Видимая звёздная величина, m» | два слайдера «от» и «до» (8,0–15,0, шаг 0,1) | выбор диапазона фильтра, значения показаны справа |
| «Найти» | кнопка | загружает галактики с видимой звёздной величиной в выбранном диапазоне |
| Карточка галактики | карточка в два столбца | фото, название, видимая звёздная величина m, расстояние в Мпк, число лайков |
| Нажатие на карточку | переход | открывает «Ленту» с этой галактики (`/feed/:id`) |

### Лента — `/feed`, `/feed/:id`

| Элемент | Тип | Что делает |
|---|---|---|
| Видео или фото галактики | на весь экран | видео по ссылке; если его нет — фото; если пусто и то и другое — видео по умолчанию |
| Название, описание, «Сверхновая …» | текст | данные галактики |
| Сердечко и число | кнопка | число лайков; поставить лайк гость не может (кнопка неактивна) |
| «m — видимая звёздная величина», «Мпк» | текст | параметры галактики |
| Стрелка «›» | кнопка | следующая галактика (после последней — снова первая) |

Без `id` открывается первая галактика ленты.

## Фото и видео по умолчанию

Файлы лежат в проекте: `src/assets/default.jpg` и `src/assets/default.mp4` (`src/media.ts`).
Они показываются, если поле `image_url` / `video_url` пустое (`null`) или файл по ссылке не загрузился.

## Данные

`src/api/galaxies.ts` сначала обращается к веб-сервису (`GET /api/galaxies`, `GET /api/galaxies/feed`,
Vite перенаправляет `/api` на `http://127.0.0.1:8001`). Если веб-сервис не отвечает, данные берутся
из mock-коллекции `src/mock.ts` с той же фильтрацией; на странице видна пометка «mock».

## Структура

```
src/
  main.tsx                  точка входа, подключение Bootstrap
  App.tsx                   маршруты и нижнее меню
  types.ts                  тип Galaxy, MagnitudeRange
  mock.ts                   mock-коллекция галактик
  media.ts                  фото и видео по умолчанию
  api/galaxies.ts           запросы к веб-сервису с переходом на mock
  pages/GalaxiesPage.tsx    страница «Плитка»
  pages/FeedPage.tsx        страница «Лента»
  components/MagnitudeFilter.tsx   фильтр по видимой звёздной величине
  components/GalaxyCard.tsx        карточка галактики
  components/BottomNav.tsx         нижнее меню из 4 пунктов
  components/Icons.tsx             иконки
  assets/default.jpg, default.mp4  фото и видео по умолчанию
```

## Хуки

| Хук | Где | Зачем |
|---|---|---|
| `useState` | `GalaxiesPage`, `FeedPage` | диапазон фильтра, список галактик, текущая галактика, признак mock, загрузка |
| `useEffect` | `GalaxiesPage` | загрузить список при открытии страницы |
| `useEffect` | `FeedPage` | загрузить галактику при смене `id` в адресе |
| `useParams` | `FeedPage` | взять `id` из адреса `/feed/:id` |
| `useNavigate` | `GalaxiesPage`, `FeedPage` | переход на ленту по карточке и к следующей галактике |
